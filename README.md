# Análise de Dados Bancários com SQL (PostgreSQL)

Este repositório contém uma coleção de 20 consultas SQL desenvolvidas para analisar o desempenho, o perfil demográfico e o comportamento financeiro dos clientes da base de dados `clientes_banco` ao longo do ano de 2024.

## Tecnologias Utilizadas

* **Banco de Dados:** PostgreSQL
* **Ferramenta de Administração:** pgAdmin 4
* **Linguagem:** SQL (Consultas analíticas, agregações, filtros temporais e Window Functions)

## Estrutura do Repositório

O projeto está organizado em diretórios individuais, onde cada pasta contém o arquivo `.txt` com a respectiva query SQL utilizada para resolver o problema de negócio:
